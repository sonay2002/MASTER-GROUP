Master Group v448 — real large dictionary loader and phrase spellcheck

- Corrected dictionary source configuration: prioritizes the public CSpell export containing 2,357,415 Russian word forms instead of a nonexistent/uncertain release asset or only Hunspell roots.
- Uses jsDelivr CORS endpoint first, then GitHub raw as fallback.
- Uses a new IndexedDB cache key so an old incomplete corpus cannot prevent downloading the improved word-form list.
- Uses binary search for known-word lookup within sorted two-letter ranges to avoid linear scanning of very large buckets.
- Keeps phrase-wide typo checking and the compact correction panel from v447.
- Free; no OpenAI API or paid inference.

Important: the large corpus is downloaded at first use, not embedded in this ZIP. Real-device download still depends on the external source being reachable and the browser allowing the request.
Source: Goudron/ru-spelling-dictionary, MPL 2.0; upstream README lists 2,357,415 CSpell UTF-8 forms.
