Master Group — Smart Dictionary v22

Dictionary size: exactly 1,000,000 unique service entries.

Structure:
1. First token = action/work operation (for example: Покраска, Монтаж, Ремонт, Замена, Установка, Сварка).
2. Second token = common work object/material (for example: Пластик, Дерево, Металл, Радиатор, Труба, Кабель).
3. Further tokens = contextual details such as location, preparation, method, finish, connection, testing, etc.

Search behavior:
- The dictionary is shared across Master Group.
- First letter searches actions.
- After the first space, the search switches to work/object suggestions.
- Action-specific objects are prioritized, while the global object dictionary remains available.
- The example "Покраска Пластик" is supported.

The corpus is split into four files of 250,000 entries each for safer loading and deployment.
