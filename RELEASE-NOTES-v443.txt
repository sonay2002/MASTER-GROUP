Master Group v443 — Stage 1: Professional dictionary improvements

Changes:
- Added targeted whole-phrase correction patterns for common Russian construction/repair services and Romanian service descriptions.
- Expanded phrase coverage for faucets/mixers, outlets, leaks, fences, ceilings, wall putty, construction waste, tile dismantling, mowing, territory cleanup, and tree cutting.
- Made indexing of the optional public Russian dictionary asynchronous in small batches to reduce UI freezes on iPhone/Safari.
- Added a 25-second abort timeout for public dictionary download attempts.
- Bounded fuzzy dictionary scans so a misspelled word cannot trigger an unbounded scan across many dictionary ranges.
- Bumped app and service-worker cache version to v443 so GitHub Pages can fetch the updated files.
- No AI models, AI API calls, or API keys were added. Firebase configuration and user data paths were not intentionally changed.

Validation:
- JavaScript syntax checks passed for the app scripts.
- All existing smoke tests passed, including dictionary, estimate, Firebase boundary, finance, offline, PWA update, and session recovery tests.

Limitations:
- The large public dictionary is still downloaded only when available and is cached on the device. This archive does not bundle the multi-million-entry corpus.
- Real-device Safari/iPhone download and cache behavior still needs to be confirmed after publishing.
