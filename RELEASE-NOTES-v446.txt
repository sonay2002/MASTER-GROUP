Master Group v446 — general dictionary spell-check engine

- Reworked the optional expanded Russian dictionary checker to find candidates near the queried word instead of scanning the start of a large prefix bucket.
- Added bounded Damerau-Levenshtein distance (supports adjacent transpositions and up to two edits) with ambiguity rejection.
- Expanded checking to Russian words of 4+ letters and preserves the original word casing when proposing corrections.
- The engine still does not silently replace user input: corrections appear as suggestions for the user to apply.
- Kept the offline built-in professional phrase rules, personal corrections, estimate calculations, Firebase data and existing UI.
- No AI provider, paid API, or API key added.
- Bumped the app and service worker cache to v446.

Important limitation: general spelling suggestions depend on successfully downloading/caching the optional public Russian word corpus. If it cannot be loaded, only the built-in offline rules work; unknown typos are not guaranteed to be detected. Real Safari/iPhone verification is still required after publishing.
